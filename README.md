# COA (ES 336) - Assignment 2: MIPS Programming

- Files `q1.asm` to `q5.asm` contain the MIPS assembly code for each question. I have assumed the usage of SPIM simulator for executing these files, and have used the corresponding syscalls.
- File `q1.asm` does not produce any output, it only stores the results in the registers specified in the question.
- The matrices produced in `q2.asm` and `q5.asm` can be printed by uncommenting the lines at the end of the file
- `q3.asm` prints out the sorted array. 
- `q4.asm` prints out the index of the searched element (or -1 if not found).
- File `q6.md` contains the disassembly of the given assmebly code.
